02 命名規範速查

固定參考，不需編輯。

項目格式範例
資料夾nx{系列}_{功能}nxsport_ump
套件名com.nomaxstudio.nx.{系列}.{功能}com.nomaxstudio.nx.sport.ump
現有系列sport / work / life / fin / game（可依新專案性質新增）

套件名稱（Package Name / Bundle ID）允許字元官方規則：

平台允許字元備註
Android小寫英文字母、數字、底線 _區段（用 . 分隔）開頭不能是數字，不能用 Java 保留字；本工具自動轉小寫、空白與符號一律轉底線
iOS英文字母、數字、句點 .、連字號 -官方規則不建議用底線，若同專案要跨 Android／iOS，最好統一只用英文字母＋數字，避免底線在iOS端造成問題

07 ☁️ 雲端同步設定 ▾ 收合

設定一次後，「環境設定／協作模式」與「專案存檔」都會改存到雲端，手機、PC 用同一組設定即可同步。此區塊的設定值只存在這台裝置的瀏覽器裡，換裝置要重新貼一次設定（但資料本身是共用的）。

尚未連接雲端同步
設定步驟： 1. 到 console.firebase.google.com 建立新專案
2. 左側選單「Build → Firestore Database」→ 建立資料庫（測試模式即可）
3. 左側「專案設定」→ 一般 → 新增網頁應用程式 → 複製顯示的 firebaseConfig 物件，整段貼到下面
4. 自訂一組「同步代碼」（像密碼，只有你知道），手機與 PC 都填同一組即可讀到同一份資料
建立 Firebase 專案與資料庫：
1. console.firebase.google.com → 新增專案
2. 左側 Build → Firestore Database → 建立資料庫（測試/正式模式皆可）
3. 若選正式模式，需到「規則」分頁貼上以下內容並發布，否則預設拒絕所有讀寫：
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /sopSync/{docId} { allow read, write: if true; } } } 取得設定值：
4. 左側「專案設定」→ 一般 → 你的應用程式 → 新增網頁應用程式（不用勾 Hosting）→ 複製 firebaseConfig
5. 同一個 Firebase 專案可以重複用在以後的新網頁工具上，不用重新申請——每個新工具換一組不同的「同步代碼」即可讓資料彼此獨立（例：yusn1006、yusn1006-notes）

已知限制：
・在 Claude App 內建預覽視窗中，SDK 檔案能載入，但無法真正連上 Firestore（連線被擋），一定要下載後用手機/PC 的瀏覽器（Chrome/Safari）開啟才會動
・Firebase 設定與同步代碼存在瀏覽器 localStorage，只有真正用瀏覽器開啟時才會被記住並自動連線
・Spark 免費方案有每日讀寫額度上限，個人自用工具正常情況下不會碰到
